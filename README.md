# weight-tracker
The WeightTracker app allows users to record their daily weight and compare it to a target weight. This app meets the needs of users who may need to track weight loss or other weight goals for various reasons.

The app has a secure login screen that authenticates/registers users in a SQLite database. Once the user successfully logs ins, they will see a main page with a simple grid UI that enables users them to add, edit, and delete weights with minimal button clicks.

I tested the app by navigating to every page and intentionally entering malicious input. I also made sure to thoroughly test the baseline function of the app and database.

I feel as if I was particularly successful in demonstrating my ability to design simply, accessible apps with self-explanatory UIs. For example, the apps color scheme, font style, and size make it easy for the user to read and interact with the app without straining their eyes.
